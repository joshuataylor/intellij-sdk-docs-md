# Internal Actions - UI Submenu

The Internal Actions UI submenu provides IntelliJ Platform plugin developers with a suite of tools to help develop, debug, and test their IntelliJ Platform project UI.

Tip:

If the menu item `Tools | Internal Actions` is not available in the IDE, then the first step is [Enabling Internal Mode](enabling-internal.html).

## The Tools Available on the UI Submenu

Here are some tools available on the UI submenu of the Internal Actions menu:

* [UI Inspector](internal-ui-inspector.html) is a tool to get an internal description with each UI element's properties.

* [LaF Defaults](internal-ui-laf-defaults.html) provides a way to lookup the key-value pair for a UI element, and the ability to prototype the color of UI Controls.

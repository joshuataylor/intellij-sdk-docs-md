# Project Wizard Tutorial

This set of tutorials shows how to manipulate the process of project creation.
Configuring the Project Wizard automatically allows you to do the following:

1. [Adding New Steps to Project Wizard](adding-new-steps.html)

2. [Supporting Module Types](module-types.html)

Note:

The main utilities to configure a custom project wizard can be found in the package
[lang-api.ide.util.projectWizard](https://github.com/JetBrains/intellij-community/tree/idea/262.8665.337/platform/lang-api/src/com/intellij/ide/util/projectWizard).

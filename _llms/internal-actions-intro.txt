# Internal Actions Menu

The `Tools | Internal Actions` menu provides plugin developers with a suite of tools to help develop, debug, and test their IntelliJ Platform plugins.

Tip:

If the menu item `Tools | Internal Actions` is not available in the IDE, then the first step is [Enabling Internal Mode](enabling-internal.html).

Click on the following topics to learn more about the `Internal Actions` menu.

* [Enabling Internal Mode](enabling-internal.html) provides instructions for enabling the Internal Actions menu.

* [UI Tools](internal-ui-sub.html) has information about some tools for inspecting and testing plugin UI.

# Components

| Component |Description |
--------------------------
| [Button](button.html) |Use a button to invoke an immediate action.              |
| [Built-In Button](built-in-button.html) |An icon placed inside an input control. |
| [Checkbox](checkbox.html) |Use checkboxes for yes/no choices or for selecting several items in a group.              |
| [Combo Box](combo-box.html) |A combo box combines a [drop-down list](drop-down.html) and an [input                 field](input-field.html), allowing the user to select a value from the list or enter a custom value.                |
| [Context Help](context-help.html) |Use context help to briefly explain how a functionality works if it is not clear from the UI and the                 application behavior:                                  * [Empty State](empty-state.html)    * [Inline Help Text](inline-help-text.html)    * [Tooltip](tooltip.html)                |
| [Description Text](description-text.html) |Description text provides explanatory information about a set of settings or a single item in a list                 or tree.                |
| [Drop-Down List](drop-down.html)   |A drop-down list is a type of button that appears in dialogs. It shows a list of choices on clicking                 it and allows selecting one option.                |
| [Got It Tooltip](got-it-tooltip.html) |A Got It tooltip informs users about a new or changed feature and gives basic information about                 it.                |
| [Group Header](group-header.html) |A group header clearly labels a group of UI controls.                |
| [Icon Button](icon-button.html) |A toolbar icon button is an icon that appears on a toolbar.                |
| [Input Field](input-field.html) |An input field allows users to enter or edit a text line using the keyboard.                |
| [Link](link.html) |Use a regular link for navigation between pages of the same window.                |
| [Notifications](notification-types.html) |Notifications inform users about the status of user or system initiated operations:                     * [Notification Balloon](balloon.html)    * [Banner](banner.html)                |
| [Progress Indicators](progress-indicators.html) |Progress indicators inform users about an ongoing operation:                     * [Loader](loader.html)    * [Progress bar](progress-bar.html)    * [Progress text](progress-text.html)                |
| [Radio Button](radio-button.html) |Use a radio button group to choose one option from 2 to 4 mutually exclusive options.                |
| [Scrollbar](scrollbar.html) |The scrollbar allows users to browse content that’s larger than the visible area, such as text or                 images, by scrolling it horizontally or vertically.                |
| [Search Field](search-field.html) |A search field is an input field that helps users locate objects, actions or text in an                 application.                |
| [Split Button](split-button.html) |A button with two parts — the main action on the left and a dropdown button with secondary actions on the right. |
| [Split Icon Button](split-icon-button.html) |A split icon button appears on a horizontal toolbar and consists of two parts: the main icon and a                 triangle icon for the action list.                |
| [Table](table.html) |Use tables so that users can review, enter or edit uniform sets of data or options. For example:                |
| [Tabs](tabs.html) |Tabs organize content in dialogs by grouping similar UI controls.                |
| [Text Area](text-area.html) |A text area allows users to enter or edit multi-line text.                |
| [Toggle Button](toggle-button.html) |The toggle button is used to switch between On and Off states.                |
| [Toolbar](toolbar.html) |A toolbar provides quick access to frequently used actions and filters. It appears in dialogs,                 pop-ups, tool windows, lists, trees, and tables.                |
| [Toolbar Drop-Down List](toolbar-drop-down.html) |A toolbar drop-down list is a type of button that appears on a horizontal toolbar and shows a list of                 choices on clicking it.                |
| [Tool Window](tool-window.html) |A tool window is a pane inside the main IDE window. For information about tool windows, see [IntelliJ IDEA Web Help](https://www.jetbrains.com/help/idea/tool-windows.html). For                 information about implementing tool windows, see [Tool Windows](tool-windows.html).                |
